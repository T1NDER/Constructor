## Constructor

### 📚 О проекте
**Constructor** — это лендинг для фирмы по управлению строительством, реализованный на React и собранный с помощью Vite. Проект представляет собой адаптацию готового дизайна: основной упор сделан на компонентный подход, корректную реализацию вёрстки и точное соответствие макету.

### 💡 Цель
Закрепить навыки разработки на React, научиться работать с компонентной архитектурой, props и условным рендерингом, а также освоить деплой SPA-приложения на GitHub Pages.

### 🛠 Выполненная работа
- Проект собран на **React + Vite**
- Реализована компонентная архитектура (Header, Footer, секции, карточки)
- Создана адаптивная и семантически правильная вёрстка
- Подключены кастомные шрифты и иконки
- Настроен деплой на GitHub Pages

### 🛠 Технологии

| Технология | Описание |
|---|---|
| React | Компонентный UI, управление состоянием |
| Vite | Быстрая сборка и dev-сервер |
| JavaScript | Логика компонентов, работа с данными |
| CSS | Стилизация, адаптивная вёрстка |
| Подключённые шрифты | Кастомная типографика проекта |
| GitHub Pages | Хостинг статической сборки |


### 🚀 Запуск проекта
```bash
# 1. Клонируйте репозиторий
git clone https://github.com/T1NDER/WisdomHub.git
cd ai-website

# 2. Установите зависимости
npm install

# 3. Запустите dev-сервер
npm run dev
```
